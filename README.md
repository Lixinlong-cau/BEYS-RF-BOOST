# Bayesian-Optimized Machine Learning for Global Wheat Productivity Analysis
Code repository for reproducing analyses and figures in the manuscript:
**A data-driven multi-objective optimization framework reveals global water–nitrogen synergies governing wheat yield and water-use efficiency**

## Overview
This repository contains the custom code used for **Bayesian-optimized machine learning modeling**, SHAP analysis, and the expanded meta-analysis framework to investigate global wheat yield, resource-use efficiency, and optimized water-nitrogen management.

## Repository Structure
├── modelcode/ # Core modeling scripts (main results)

├── Supplementary/ # Supplementary analysis & SHAP plotting code

└── README.md # Repository documentation


## Reproducibility Instructions
- **Data for Figure 2, Figure 3, Supplementary Figure 2, 7, 8, 9**  
  Generated by running scripts in the `modelcode/` directory.
- **Supplementary Figures 3–6 (both figures and underlying data)**  
  Directly generated by running scripts in the `Supplementary/` directory.

## Core Functions
- Bayesian optimization for machine learning model hyperparameters
- Ensemble model training and prediction
- SHAP feature importance and interaction analysis
- Expanded meta-analysis framework
- Visualization for main and supplementary figures
